## 3. 개발 주제 정하기*****중요

### 3-1. 주제

    #### (1) 독서 기록 사이트
    - 읽은 책 제목, 내용, 느낀점 입력
    - 별점
    - 북마크
    - 기록 검색

    #### (2) 비밀번호 관리 프로그램
    - 사이트, 아이디, 비밀번호 입력
    - 2차 인증
    - 사이트 검색
    - 매번 까먹는 비밀번호를 한 곳에서 저장
    - 메모장으로도 가능할 것 같아 차별점이 필요할 수 있음

    #### (3) 랜덤 데이트 코스 생성기
    - 커플들을 위한 새로운 콘텐츠
    - 지역 선택 후 장소 랜덤 추천
    - 카페
    - 영화관
    - 기타 데이트 장소
    - 주사위 기능
    - 사용할 예산 랜덤 생성
    - 가능한 예산을 입력하면 해당 범위에서 랜덤으로 사용
    - 콘텐츠 이용 후 만족도 리뷰 작성

    #### (4) 선물 추천 프로그램
    - 받는 사람 정보 입력
    - 친구
    - 연인
    - 부모
    - 가족 등
    - 원하는 가격대 입력
    - 선물 추천
    - 추천된 선물 클릭 시 관련 사이트로 연결
    - 구현이 다소 복잡할 수 있음
